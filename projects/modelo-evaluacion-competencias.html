Modelo de Evaluación de Competencias Digitales

Modelo relacional y herramienta automatizada de evaluación construida en Excel para transformar una jerarquía de competencias, criterios y evidencias en resultados calculados, trazables, validados y documentados.

Excel Power Query Modelado de datos Testing QA Automatización Modelos jerárquicos

Objetivo

Construir en Excel una herramienta robusta capaz de convertir criterios de evaluación jerárquicos en reglas matemáticas, puntuaciones y resultados comparables sin perder trazabilidad.

Problema resuelto

Los modelos de evaluación complejos requieren mantener relaciones entre competencias, subcompetencias, situaciones y descriptores, aplicar ponderaciones correctamente y controlar datos incompletos o combinaciones inválidas.

Resultado

Un libro estructurado por capas que separa configuración, datos, cálculos, resultados, dashboard, testing, staging, diccionario y documentación para facilitar su uso, mantenimiento y auditoría.

Arquitectura

De criterios de negocio a un modelo evaluable

El libro separa explícitamente las responsabilidades del modelo para evitar mezclar entradas, reglas, cálculos, resultados y controles en una única hoja.

1. Datos

Parámetros, personas y catálogos normalizados de competencias, subcompetencias, situaciones y descriptores forman la base estructurada del modelo.

2. Cálculo

Las evaluaciones se transforman en puntuaciones y se agregan progresivamente respetando cada nivel jerárquico y sus ponderaciones.

3. Control

Casos de prueba, ejecución de tests, controles de cobertura, diccionario y documentación permiten comprobar que el modelo sigue comportándose como se espera.

Modelo de datos

Una jerarquía que mantiene el significado del negocio

Cada evaluación debe respetar las relaciones existentes entre los distintos niveles. El modelo evita combinar directamente elementos que pertenecen a niveles diferentes.

Competencias

Constituyen el nivel superior del modelo y agrupan las grandes áreas que se quieren evaluar.

Subcompetencias

Descomponen cada competencia en dimensiones más específicas que pueden tener sus propias ponderaciones.

Situaciones y descriptores

Representan el nivel observable de la evaluación y permiten asignar evidencias, niveles cualitativos y puntuaciones.

Motor de cálculo

Ponderaciones y agregación jerárquica

El cálculo no obtiene directamente un resultado global desde las observaciones. Cada nivel se calcula y consolida antes de alimentar el siguiente.

Score de subcompetencia

Las situaciones observadas se agregan dentro de su subcompetencia utilizando únicamente los pesos disponibles para esa evaluación.

Score de competencia

Los resultados de las subcompetencias se ponderan para obtener la puntuación de competencia sin mezclar directamente situaciones de niveles inferiores.

Score global

Finalmente se agregan las competencias disponibles para obtener un resultado global comparable junto con indicadores de cobertura.

Flujo de trabajo

Del modelo a la interpretación

El libro incorpora un recorrido definido para que configuración, mantenimiento, evaluación y validación formen parte del mismo proceso.

Configura y modela

Se revisan parámetros, niveles, personas y pesos y se mantienen los catálogos jerárquicos normalizados.

Evalúa y calcula

Las observaciones se introducen mediante relaciones controladas y el motor genera automáticamente puntuaciones y agregaciones.

Interpreta y valida

Resultados y dashboard permiten analizar el modelo mientras la suite de pruebas comprueba que la lógica continúa siendo coherente.

Testing y QA

El modelo también se prueba

Una herramienta de evaluación no debería considerarse terminada únicamente porque sus fórmulas funcionen. El libro incorpora una matriz específica para validar matemáticamente y funcionalmente sus reglas.

15 escenarios

La suite incluye límites, combinaciones, datos faltantes, entradas inválidas y comparaciones entre resultado esperado y resultado calculado.

PASS / FAIL

Cada caso comprueba automáticamente el comportamiento del modelo y permite detectar diferencias fuera de la tolerancia definida.

Panel de ejecución

La hoja de ejecución resume número de pruebas, resultados, cobertura y fallos detectados para facilitar el control de calidad antes de validar una versión.

Preparado para integración

Capa de staging y Power Query

El proyecto incluye una capa diseñada para representar cómo podrían incorporarse datos procedentes de fuentes externas antes de alimentar las evaluaciones.

Staging

Una tabla específica separa los datos importados de las tablas operativas del modelo y permite controlar su procedencia.

Calidad de origen

Se contemplan controles sobre claves, calidad de fila, archivo de origen y momento de carga para aportar trazabilidad al proceso.

Plantilla M

El libro documenta un patrón Power Query para importar, tipar, limpiar y validar datos. Se presenta como plantilla de integración y no como una conexión externa activa.

Gobierno y documentación

Un modelo pensado para poder mantenerse

La documentación forma parte de la solución y no se trata como un elemento externo al libro.

Guía de uso

Explica el flujo recomendado para configurar, mantener, evaluar, calcular, interpretar y validar el modelo.

Diccionario de datos

Documenta campos, tipos, significado, propiedad de edición y principales reglas de negocio.

Manual integrado

Resume la finalidad de cada hoja, sus dependencias, controles y procedimiento de mantenimiento para que el libro pueda ser entendido y auditado.

Modelo interactivo

Explora el Excel completo

Recorre directamente el modelo publicado en Excel para la Web: datos, cálculos, resultados, dashboard, pruebas, Power Query y documentación.

Valor diferencial

Por qué este proyecto es relevante

El proyecto demuestra que Excel puede utilizarse para construir algo más que una hoja de cálculo: un modelo estructurado, mantenible, auditable y sometido a pruebas.

Separación de responsabilidades

Datos, reglas, cálculos, resultados y controles permanecen separados para reducir errores y facilitar el mantenimiento.

Trazable y validable

Las reglas pueden seguirse desde la observación original hasta el resultado global y comprobarse mediante casos de prueba reproducibles.

Escalable

La arquitectura permite ampliar catálogos, personas, criterios, fuentes externas y nuevas reglas manteniendo una estructura común.
