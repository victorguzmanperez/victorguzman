Investment Dashboard con IA

Plataforma personal de análisis de inversiones desarrollada con Python y Power BI para evaluar dividendos, riesgo, valoración, noticias y optimización de cartera.

Objetivo

Construir una plataforma propia para analizar activos, carteras, dividendos, riesgo y señales de mercado desde una perspectiva cuantitativa y explicable.

Problema resuelto

La información financiera suele estar dispersa entre precios, dividendos, fundamentales, noticias y métricas de riesgo. Este proyecto busca integrarlo todo en un sistema único para apoyar decisiones de inversión basadas en datos.

Tecnologías utilizadas

Python · Power BI · Parquet · APIs financieras · Scoring · Optimización · IA · DAX · Automatización

Arquitectura

De datos financieros a motor de decisión

El proyecto combina ingesta de datos, cálculo de métricas, scoring, optimización y visualización para construir una herramienta de análisis de inversión.

1. Datos

Precios, dividendos, fundamentales, divisas, noticias y universo de activos.

2. Modelos

Cálculo de rentabilidad, riesgo, dividend quality, valoración, scoring y optimización de cartera.

3. Decisión

Power BI e IA ayudan a interpretar señales, comparar activos y priorizar oportunidades.

Estado

Proyecto en desarrollo

Este dashboard todavía no está publicado. El objetivo es evolucionarlo hacia una plataforma completa de análisis, seguimiento y optimización de inversiones.
